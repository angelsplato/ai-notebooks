# Pinned dependency stack for the ai-notebooks experiments.

# The notebooks were written for TensorFlow 2 / Keras 2 (circa 2019-2021) and
# the classic pre-0.26 OpenAI Gym API where ``env.step`` returns a 4-tuple and
# ``env.reset`` returns a bare observation. They also rely on Keras 2 Functional
# API leniency (raw ``keras.backend`` ops on symbolic tensors + ``add_loss``),
# which the final Keras 2 release (2.16) and Keras 3 reject.
#
# TensorFlow 2.12 (bundled Keras 2.12) is the newest release that still runs
# these notebooks unmodified. It requires Python <= 3.11, so the environment
# provisions Python 3.11 (see .cursor/install.sh) rather than the image default.
#   * numpy < 1.24 -> use 1.23.x/1.24.x band pinned by TF 2.12
#   * gym 0.25.2 keeps the 4-tuple step / reset-returns-observation API
#   * box2d-py provides LunarLander (needs swig at build time)
